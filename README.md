# 🔍 HelloWorld-OSINT

A simple Python-based OSINT tool for phone number investigation.

## Features
- Phone validation
- Carrier lookup (NumVerify)
- Google dorks
- Breach check guidance

## Installation
```bash
git clone https://github.com/your-username/HelloWorld-OSINT.git
cd HelloWorld-OSINT
pip install -r requirements.txt
```

## Usage
```bash
python hello_world.py +919876543210
```
